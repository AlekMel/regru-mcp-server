# Спецификация Reg.API 2.0 для реализации MCP-сервера (Model Context Protocol)

> **Назначение документа:** Исчерпывающее техническое задание и эталонная архитектурная спецификация для ИИ-агента разработки (AI Software Engineer), создающего промышленный MCP-сервер для работы с инфраструктурой аккредитованного регистратора и хостинг-провайдера [Рег.ру (REG.RU)](https://www.reg.ru/reseller/api2doc).
> Документ объединяет полную детализацию протокола REG.API 2.0, все 116 методов с описанием параметров, ошибок и нюансов валидации, а также готовую архитектуру инструментов (MCP Tools), динамических ресурсов (MCP Resources) и сценариев (MCP Prompts).
